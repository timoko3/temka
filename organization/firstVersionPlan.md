# Первая версия 
- Думаю для начала стоит сделать версию некого "движка частиц"
- сразу на самом первом этапе надо будет делать графический движок тестирования. То есть всю логику физическую которую будем делать сразу удобно будет визуально отлаживать. Это уже звучит как первая такая вилка разделения обязанностей договариваемся об общем интерфейсе между физ движком и графической системой тестирование и отдельно работаем над ними
- Потом потиху лезем в 2d движок твердого тела ( система графического тестирования по прежнему под новые задачи должна будет совершенствоваться)
- В конечном счете просто система граф отладки должна вырасти до полноценной 3d симуляции aka граф движка так что писать с умом надо и с расчетом на это.

Идея для уникальности: автоматический подбор параметров по видео. То есть есть условно как нибудь отскакивающий шарик на видео и повторить сцену с этим шариком максимально точно в движке. Возможно немного затронуться нейронки и их обучение что тоже полезно и интересно (уже не первая версия конечно)
